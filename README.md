# Acervo Histórico Celeste - Trabalho de Programação Web

**Aluno:** Guilherme Pereira Scatolino
**Curso:** Engenharia de Computação **Turma:** GNP0542 3001

Este projeto da disciplina de Programação Web. Trata-se de um acervo focado em preservar a memória dos maiores ídolos da história do Cruzeiro Esporte Clube.

## Como Executar

O projeto foi construído de forma puramente estática e não necessita de instalação de pacotes, dependências ou servidores complexos nesta fase.

Para visualizar:

1. Clone este repositório ou baixe os arquivos.
2. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador de preferência.

## Auditoria W3C e Formulários

O código HTML passou na validação oficial do W3C com **0 erros** apontados, garantindo o respeito aos padrões da web.

## Auditoria Lighthouse

O site foi submetido à auditoria do Lighthouse no navegador para verificar responsividade e acessibilidade. O layout foi testado em telas pequenas e não apresenta rolagem horizontal (scroll) na resolução mínima de 320px.

Abaixo estão as notas finais obtidas:

- **Acessibilidade:** 100
- **Performance:** 99
- **Melhores Práticas:** 100
- **SEO:** 91
- **Agentic Browsing:** 2/2

## Uso de Inteligência Artificial

Para a construção deste projeto, utilizei a inteligência artificial (Gemini/Antigravity) como uma ferramenta de auxílio. A IA ajudou a gerar a estrutura inicial da marcação em HTML semântico e também na montagem inicial do layout com CSS Grid.

No entanto, todo o código gerado foi revisado por mim. Refatorei e reescrevi o aninhamento das tags para eliminar problemas de "div soup" que a IA havia inserido, e também ajustei e corrigi as variáveis do Design System (`style.css`) para garantir que as cores batessem exatamente com os tons oficiais do clube, garantindo o padrão exigido nas aulas.
