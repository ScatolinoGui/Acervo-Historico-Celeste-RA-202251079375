## Descrição do Projeto
Um acervo histórico para preservar a memória e estatísticas dos maiores ídolos do Cruzeiro Esporte Clube. O projeto apresenta uma galeria de jogadores lendários e um formulário validado nativamente para sugestão de novos nomes.

## Como Executar
O projeto da Fase 1 é puramente estático (HTML/CSS). Basta clonar o repositório e abrir o ficheiro `index.html` em qualquer navegador web, sem necessidade de servidores locais.

## Acessibilidade
O projeto foi desenvolvido com HTML semântico (`<main>`, `<article>`, `<header>`) e contraste de cores adequado. O formulário utiliza os atributos `for` nos `<labels>` associados aos `ids` dos inputs, garantindo navegação por teclado e pontuação elevada no Lighthouse.

## Uso de IA
- **Ferramentas usadas:** IA (Gemini / Antigravity).
- **Onde ajudou:** Geração do esqueleto HTML5 semântico, estruturação do CSS Grid para a galeria e aplicação dos atributos de validação nativa (pattern, min, max, required) no formulário.
- **O que eu revisei/reescrevi:** Adaptação do Design System com as Variáveis CSS (Custom Properties) para as cores oficiais do Cruzeiro, definição dos textos de conteúdo e organização da estrutura de pastas.
